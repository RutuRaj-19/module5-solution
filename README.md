# Module 5 Solution

This project is a restaurant web application for the Coursera Front-End Web Development course.

## Features
- Home page with interactive tiles
- Menu categories view
- Single-category menu items view
- Random Specials tile behavior that opens a random category

## Project Structure
- `index.html` — Main page entry point
- `css/` — Stylesheets
- `js/` — JavaScript application logic
- `snippets/` — HTML partial templates
- `images/` — Images used by the site

## How to Run
Open `index.html` in a browser, or serve the project using a local web server.

## Deployment
This project can be published on GitHub Pages by enabling Pages for the repository and pointing it to the project folder.
